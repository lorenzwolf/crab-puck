🦀 Crab Puck

A desk crab that shows what Claude Code is doing. Flash it to a LilyGO TTGO T-Display from your browser.

  1. Plug the T-Display into this computer with a USB-C data cable.
  2. Click the button and pick the board's serial port.
  3. Choose Install. This erases whatever is on the board.

Your browser can't flash boards. Use Chrome or Edge on a desktop. Flashing needs a secure (https) page.

If no port shows up, install the board's USB driver (CH9102 or CP2104). If flashing won't start, hold the bottom button while clicking Connect.

Next: add the hooks to Claude Code.
  1. pip install pyserial
  2. In Claude Code: /plugin marketplace add lorenzwolf/crab-puck
  3. Then: /plugin install crab-puck@crab-puck
